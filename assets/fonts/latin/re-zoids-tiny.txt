# re-zoids tiny Latin pixel font. Original work of the re-zoids-saga project,
# GPL-3.0-only like the rest of the repository.
#
# Small capitals five pixels tall for the port's small notices: each glyph
# is 13 rows like the Latin font's, the letters on rows 4-8 so accents fit
# on rows 1-2, and a comma hangs to row 9. Lower case draws with these
# capitals. `#` is ink, `.` is empty; the width is the row length and the
# advance is one pixel more.
