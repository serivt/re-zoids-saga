# re-zoids Latin pixel font. Original work of the re-zoids-saga project,
# GPL-3.0-only like the rest of the repository.
#
# Each glyph is 13 rows in a box: rows 0-1 hold accents, capitals and
# ascenders start at row 2, the x-height at row 5, the baseline is row 9
# and descenders use rows 10-12. `#` is ink, `.` is empty; the width is
# the row length and the advance is one pixel more.
