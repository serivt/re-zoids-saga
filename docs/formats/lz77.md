# LZ77 compression

Source of knowledge: public hardware documentation (GBATEK, "BIOS Decompression
Functions": `LZ77UnCompWram` / `LZ77UnCompVram`). Implemented in
`crates/formats/src/lz77.rs`.

| Part | Layout |
|---|---|
| Header | 32-bit little-endian: low byte `0x10`, upper 24 bits = decompressed size |
| Group | one flag byte, then 8 items; bit 7 of the flags governs the first item |
| Literal (flag 0) | 1 byte copied to the output |
| Reference (flag 1) | 2 bytes: `(length - 3) << 4 \| (distance - 1) >> 8`, then `(distance - 1) & 0xFF`; copies `length` bytes from `distance` bytes back, overlapping allowed |

Decoding stops once the declared size is reached, so a final group may be partial.

Zoids Saga compresses most graphics this way; the blocks the game decompresses during
boot, the title screen and the first dialogue were logged from the reference emulator:

| ROM offset | Destination | Content |
|---|---|---|
| `0x061750` | VRAM `0x2040` | Title screen tiles |
| `0x06310C`, `0x063414` | VRAM | Title screen tiles |
| `0x06EA68` | palette RAM `0x000` | Background palettes 0–14 (480 bytes) |
| `0x06EB18` | VRAM `0x8000` | Title screen |
| `0x3B9428` | VRAM `0x2800` | Text window frame ([window.md](window.md)) |
| `0x4142B8` | VRAM `0x8000` | First map tiles |
| `0x4B6788`, `0x4B6940`, `0x4B6A54` | OBJ VRAM | Sprites of the first scene |
| `0x4B6834`, `0x4B69C0`, `0x4B6A68` | OBJ palettes | Sprite palettes of the first scene |
